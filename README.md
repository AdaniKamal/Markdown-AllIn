# Markdown All In

Markdown All In is a lightweight website for previewing, writing, and learning Markdown. It does not require signup, a backend, or a database. Users can upload a Markdown file, paste Markdown text, write with live preview, generate a heading tree, and refer to a beginner-friendly Markdown wiki.

## Project Purpose

This project is built for people who want a simple Markdown workspace without needing to install anything. It is suitable for README drafting, note writing, documentation planning, and teaching Markdown basics.

## Current Features

| Feature | Description |
| --- | --- |
| Markdown viewer | Upload a `.md`, `.markdown`, or `.txt` file and preview it in the browser. |
| Paste-to-preview | Paste Markdown text directly into the viewer and render it instantly. |
| Live editor | Write Markdown on the left and see the preview update on the right. |
| Formatting toolbar | Insert H1, H2, H3, bold, italic, quote, bullets, numbering, inline code, table, and links. |
| Markdown tree generator | Write or paste editable Markdown headings and generate a copy-ready ASCII tree. |
| Markdown wiki | Learn common Markdown syntax through clear, readable examples. |
| Copy actions | Copy written Markdown or the generated tree structure. |
| MD tab icon | Identify Markdown Studio quickly through its custom browser-tab icon. |
| Light theme | Clean, calm interface using a soft light color palette. |
| Responsive layout | Works across desktop and mobile screen sizes. |
